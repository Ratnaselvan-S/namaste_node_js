Node modules /bin folder
------------------------
    -> The node_modules/.bin folder contains executable CLI files of installed packages.When a package provides a command-line tool, npm creates a symlink here.
    It allows you to run tools locally without installing them globally.
    npm run automatically uses commands from this folder.
