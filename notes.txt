JavaScript Object	          |  JSON
Exists inside JavaScript	  |  Data format (text format)
Can store functions	          |  Cannot store functions
Keys can be without quotes	  |  Keys must be in double quotes
Used in runtime memory	      |  Used for data transfer
Can use single quotes	      |   Only double quotes allowed
