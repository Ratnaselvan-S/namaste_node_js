Order of the route matters
--------------------------
    example -> app.use("/", (req, res) => {
                res.send("server noted");
                });
                app.use("/test", (req, res) => {
                res.send("server tested");
                });
            ->when we type "localhost:3000/" or "localhost:3000/test" it will print "server noted" for both as the order of the path we arite matters

    example -> app.use("/test", (req, res) => {
                res.send("server tested");
                });

                app.use("/test/2", (req, res) => {
                res.send("server 2 tested");
                });

            ->likewise the above this also prints "server tested" for both route 

    *imp app.use handles all data starting with the path (refer above example) but app.get or post match exactly that path *
    *Never put app.use before any get or post because the path even if we mentioned get /user it will not not executed if we put app.use("/user")*


app.get('/ab?c') -> in this route when we request "abc it works" and  "ac also works because of question mark"

app.get("/ab+c) => in this route when we request "abbbbbbbbbbbbbc it works" and "abccc  it wont work"

app.get("/ab*cd) => in this route anything between ab and cd it works like "acaksaycd it works" make sure start and end is correct

app.get("/a(bc)?d) ->  in this route when we request "ad it works" and  "acd not works"

we can also put regex in the route
---------------------------------------

app.get(/a/) this is regex here anything starts with a works

app.get(/.*fly$/) all route which ends with fly will be handled here



req.query for after ? mark in req

req.params dynamic path route app.get("/users/:id")
