 Router handler
 -------------------
    ->  when a user request a '/user' and in backend we did not send responce like res.send then the request keeps on loading untila responce or timeout of the request came


example
---------
app.use(
  "/user",
  (req, res, next) => {
    console.log("respnce");

    // res.send("first responce");
    next();
  },
  (req, res) => {
    console.log("second");
    res.send("second responce");
  },
);

-> here when we req users console log responce will be printed and next when it is not there it will just leave it be , and if next is there the nextrouter function execute and 
    second is printed and second responce is also printed and second responce is sended 

    *remember for a route only one res need to be send multiple responce gives error , so the concept here is when the users req a socket is created and when the responce 
    is sent then the socket is closed , so we cant send multiple res *

-> i can wrap the multiple router handler in array also

-> we can also define two or more router handler with same path and write next inside
