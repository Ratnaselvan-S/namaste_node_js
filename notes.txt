       ->  When execution reaches require() in main.js, Node.js loads the target file (for example math.js), wraps it inside an IIFE (module wrapper),
        and executes it immediately.
        During execution, only the variables or functions assigned to module.exports are exposed.
        Exported primitive values are returned by value, while objects and functions are returned by reference from heap memory.
        After the module finishes execution and is removed from the call stack, require() returns the value referenced by module.exports.
